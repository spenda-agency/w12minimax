# assets/

brief から参照する自前素材の置き場です。

| ディレクトリ | 用途 |
|---|---|
| `bgm/` | BGM（mp3 / wav）。brief の `bgm.path` から参照 |
| `brand/` | ロゴ・ブランドカラー見本など、生成させずに合成する正規データ |

## 注意

- **BGM は生成せず、ライセンスを確認したものを使ってください。** 商用広告利用可の範囲かどうか（YouTube / Meta での配信を含む）を必ず確認すること。
- 音声・動画ファイルは `.gitignore` で除外しています。権利上コミットしてよいものだけ、
  `git add -f` で明示的に追加してください。
- ロゴは AI に生成させず、ここに置いた正規データを使います。
